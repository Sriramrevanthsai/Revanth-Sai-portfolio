# Sriram Revanth Sai — Portfolio

A responsive, single-page portfolio website built with plain HTML and CSS.

## Preview locally
Open `index.html` in any browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `portfolio`.
2. Upload `index.html` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public website URL after deployment.

You can also deploy the folder using Vercel by importing the repository.
