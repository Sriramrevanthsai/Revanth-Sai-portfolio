# Sriram Revanth Sai — Portfolio

A responsive portfolio website featuring the supplied profile photo, resume PDF, experience, skills, and selected GitHub projects.

## Preview locally
Open `index.html` in a browser. Keep `profile-photo.png` and `Revanth_Sai_Sriram_Resume.pdf` in the same folder.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload all three files: `index.html`, `profile-photo.png`, and `Revanth_Sai_Sriram_Resume.pdf`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub Pages will show your public portfolio URL after deployment.

## Before publishing
Check that every description and metric is current. The project cards link to repositories visible on your public GitHub profile. The PoetryPal card links to your profile because its individual repository URL was not confirmed from the profile page.
